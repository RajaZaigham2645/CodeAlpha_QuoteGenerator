Random Quote Generator App 📜✨
Overview

Random Quote Generator is an Android application developed using Java and XML in Android Studio. The app displays inspirational and motivational quotes randomly, providing users with a fresh quote each time they interact with the application.

Features
🎲 Generate random quotes with a single tap
📱 Clean and user-friendly interface
⚡ Fast and lightweight performance
🎨 Simple and responsive UI design
📖 Collection of inspirational and motivational quotes
Technologies Used
Java – Application logic
XML – User Interface design
Android Studio – Development environment

How It Works
Launch the application.
Tap the Generate Quote button.
A random quote is displayed on the screen.
Tap again to receive another quote.
Installation

Clone the repository:

git clone https://github.com/RajaZaigham2645/RandomQuoteGenerator.git
Open the project in Android Studio.
Sync Gradle files.
Build and run the application on an Android device or emulator.
